# BalanceBoard

BalanceBoard is a student wellness and study-life tracker built with React and Vite.

## Initial Setup

This repository currently contains:

- React + Vite
- React Router
- Initial reusable folder structure
- Placeholder pages
- Responsive navigation
- BalanceBoard design variables
- Mock JSON data

## Installation

```bash
npm install
npm run dev
```

## Initial Routes

- `/` - Login
- `/dashboard` - Dashboard
- `/analytics` - Analytics
- `/calendar` - Calendar
- `/achievements` - Achievements
